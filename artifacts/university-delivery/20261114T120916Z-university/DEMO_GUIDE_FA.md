# راهنمای کوتاه دمو

این بسته کاندید نصب است و وضعیت پذیرش کامل آن NOT_READY است. U1 ذخیره‌شده موفق بوده و U2 پیش از حل شکست خورده؛ پرامپت صورت‌بند rc2 فقط آفلاین اصلاح شده است.

۱. ZIP را استخراج و طبق DELIVERY_GUIDE_FA.md با Python 3.12 نصب کنید. برای داده مستقل همان --data-dir را در شروع و توقف نگه دارید.

۲. در تنظیمات موجود، endpoint، مدل و کلید شخصی را تنظیم کنید. کلید در بسته نیست. برنامه و حل محلی‌اند و مدل از API استفاده می‌کند.

۳. «منابع و الگوریتم‌ها ← الگوریتم‌ها ← آماده‌سازی نسخه دانشگاهی» را اجرا کنید. شش روش ABC/PSO/CMA-ES/DE/GWO/WOA و اسناد رسمی باید آماده شوند. گواهی معتبر دوباره مصرف نمی‌شود؛ بودجه آماده‌سازی تجمعی است.

۴. برای نمایش نتیجهٔ موجود بدون تماس تازه، HTML گزارش ذخیره‌شده U1 را باز کنید. جواب [1.4,-2.2]، مقدار صفر، برنده PSO، نه پایلوت و پنج بخش مدل را نشان دهید. این خروجی متعلق به rc1 است؛ بازکردن آن اثبات پذیرش زنده rc2 نیست.

۵. در گزارش U2 نشان دهید که صورت‌بندی به‌اشتباه درخواست گردش‌کار را خارج از دامنه تشخیص داده؛ جواب، نامزد و نمودار ساخته نشده است. نتیجهٔ FAIL و تلاش اول محفوظ‌اند.

۶. برای تست دستی تازه، ورودی فارسی را در «حل مسئله» وارد و روش پژوهش/مقایسه را انتخاب کنید. اجرای دستی بعدی، مستقل از کمپین پذیرش بسته‌شده و با هزینهٔ احتمالی API است. آن را به‌عنوان تکمیل پذیرش قبلی نشمارید.

دامنه: قطعی، تک‌هدفه، پیوسته، ۲ تا ۳۰ متغیر حقیقی کراندار. نتیجه، بهترین مشاهده بررسی‌شده میان نامزدهای همان اجرا و در بودجهٔ مشخص است؛ تضمین روش برتر جهانی یا گواهی عمومی بهینگی نیست.
