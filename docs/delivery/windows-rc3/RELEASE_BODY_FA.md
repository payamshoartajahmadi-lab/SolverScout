این **Pre-release** اولین تحویل دانشگاهی SolverScout برای **ویندوز با اجرای یک نمونه در هر زمان** است. نسخهٔ فنی برنامه `2.1.0rc3` و تگ انتشار `v2.1.0-rc.3` است. نصب تمیز ویندوز تأیید شده؛ معیار AC14 نصب تمیز مک هنوز تکمیل نشده و وضعیت کلی ماتریس پذیرش **NOT_READY** باقی می‌ماند.

**قابلیت و دامنه**

SolverScout صورت‌بندی مسئله، پیشنهاد سه نامزد از فهرست روش‌های معتبر، مقایسهٔ پایلوت، حل عددی محلی با بودجهٔ مشخص و گزارش مستند را یکپارچه می‌کند. شش روش هدف ABC، PSO، CMA-ES، DE، GWO و WOA هستند. مدل زبانی از طریق API برای صورت‌بندی، پیشنهاد و توضیح به کار می‌رود؛ انتخاب نهایی بر نتایج پایلوت متکی است.

دامنهٔ این تحویل مسائل قطعی، تک‌هدفه و پیوسته با ۲ تا ۳۰ متغیر حقیقی و کران‌های متناهی است. قید عمومی، متغیر صحیح، چندهدفه و تابع تصادفی پشتیبانی نمی‌شوند. خروجی بهترین مشاهدهٔ معتبر در بودجهٔ اجراست؛ تضمین بهینگی سراسری ندارد.

اصلاحات rc3 شامل رفع مشکل DNS ویندوز و سیاست تولید گزارش `1.3` است: فقط ارجاع شناخته‌شده، اختیاری و استفاده‌نشده از فرادادهٔ همان بخش حذف می‌شود؛ متن و شواهد ثابت می‌مانند و اعتبارسنج سخت‌گیر و بازبینی معنایی همچنان اجرا می‌شوند.

موفقیت گزارش rc3 **پذیرش گزارش بازتولیدشدهٔ U1 بر پایهٔ محاسبات ذخیره‌شده** است، نه اجرای کامل تازهٔ حل مسئله. برای ادغام و انتشار، آزمون کامل، تماس مدل، qualification یا حل عددی دوباره اجرا نشده است.

**نصب و آماده‌سازی مقصد**

فایل ZIP و راهنمای پیوست `WINDOWS_RC3_INSTALL_FA.md` را دریافت کنید. Python 3.12 نسخهٔ ۶۴بیتی لازم است. بسته را در پوشه‌ای تازه استخراج و طبق راهنما `scripts\setup.bat`، سپس `scripts\doctor.bat` و `scripts\start.bat` را با یک data-dir مستقل اجرا کنید. setup یک smoke عددی با سقف ۱۰۰۲ ارزیابی دارد؛ برای اجرای روزانه فقط start لازم است.

برای قابلیت‌های مدل، از «تنظیمات ← اتصال مدل زبانی» سرویس، مدل و کلید شخصی را تنظیم کنید و نگهداری کلید را «مخزن امن سیستم‌عامل» قرار دهید. بسته کلید API یا دیتابیس خصوصی ندارد. استفاده از API و تست اتصال هزینه و مصرف جداگانه دارند.

پیش از دموی دانشگاهی، «آماده‌سازی نسخهٔ دانشگاهی» در «منابع و الگوریتم‌ها ← الگوریتم‌ها» را برای شش روش و منبع رسمی اجرا کنید؛ گواهی‌ها وابسته به محیط مقصد هستند. آماده‌سازی عددی در بررسی نصب تمیز انجام نشده است. مسیر CLI همان `prepare-demo` با سقف تجمعی ۱۰۰۰۰۰ ارزیابی است و باید هنگام توقف نمونهٔ مالک همان data-dir اجرا شود.

**محدودیت‌ها**

- در ویندوز فقط یک نمونه در هر زمان، حتی با پورت یا data-dir متفاوت، اجرا کنید. علت شکست تاریخی نمونهٔ هم‌زمان دوم با `START_FAILED` / `NUMERIC_POLICY_ENVIRONMENT_MISMATCH` هنوز حل نشده است؛ این خطا در نصب مستقل و restart آن تکرار نشد.
- نصب تمیز مک و مسیر کامل AC14 هنوز تأیید نشده‌اند. این انتشار نتیجهٔ ویندوز را به مک تعمیم نمی‌دهد؛ Linux و macOS Intel نیز در این مرحله آزموده نشده‌اند.
