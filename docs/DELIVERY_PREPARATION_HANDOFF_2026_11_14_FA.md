# اطلاعات آغاز مرحلهٔ آماده‌سازی تحویل — ۲۰۲۶/۱۱/۱۴

آمادگی **NOT_READY** است؛ نسخهٔ تازهٔ پذیرفته‌شده برای تحویل وجود ندارد. علت، شکست کیفیت متن C-L4 در مأموریت نهایی گزارش‌دهی است. نسخهٔ آزموده‌شده `a4703f0f543eb98a637a46251f3568b8051c66d5` در شاخهٔ `fix/narrative-final-closure` است؛ به dev ادغام نشده است. نتیجهٔ کامل در [گزارش این مأموریت](FINAL_NARRATIVE_CLOSURE_2026_11_14_FA.md) و فایل محلی `artifacts/narrative-v3-closure/20261114T053456Z-700969c/Delivery_Preparation_Handoff_FA.md` قرار دارد. سند handoff قبلی حفظ شده است.

برنامه محلی است و مسائل قطعی، تک‌هدفه، با ۲ تا ۳۰ متغیر حقیقی و کران‌های متناهی را پوشش می‌دهد. قید عمومی، متغیر صحیح و اثبات نمادین در دامنهٔ نسخهٔ فعلی نیستند. بهترین مشاهدهٔ تأییدشده در بودجه، گواه بهینگی جهانی نیست.

محیط این مأموریت macOS روی arm64 با Python 3.12.16 بوده است. نصب تمیز، Windows و رایانهٔ استاد در این مأموریت بررسی نشده‌اند. وجود اصلاحات Windows در تاریخچه، جای آزمون این مرحله را نمی‌گیرد.

از ریشهٔ پروژه و محیط موجود `.venv`، راه‌اندازی با `python run_server.py` و توقف با `python run_server.py stop` است. برای مسیر دادهٔ انتخابی، `--data-dir` در اجرا و توقف یکسان باشد. wrapperهای موجود `scripts/start.sh` و `scripts/stop.sh` و تنظیم `examples/config.example.json` نیز در پروژه هستند. اسکریپت نصب در این کمپین اجرا نشد، چون می‌تواند smoke عددی اجرا کند.

ورود کلید در رابط از «تنظیمات» ← «تنظیمات مدل زبانی» انجام می‌شود. تماس مدل به اینترنت و اعتبار API نیاز دارد. ذخیرهٔ دائمی کلید به مخزن امن سیستم‌عامل وابسته است؛ کلید نشست با توقف API ماندگار نیست. هیچ کلید، cookie یا credential store نباید با بستهٔ توزیع منتقل شود.

محل داده با resolver فعلی platformdirs برای `P_MC_Optimizer` تعیین می‌شود؛ `--data-dir` آن را عوض می‌کند. مسیر واقعی با فرمان doctor موجود قابل مشاهده است. SQLite، checkpoint، گزارش‌ها و زیرپوشهٔ logs متعلق به همین محل‌اند. سورس و دادهٔ خصوصی دو محتوای جدا هستند.

وابستگی‌ها در `pyproject.toml`، `requirements.lock` و `requirements-test.lock` ثبت شده‌اند؛ در این مأموریت dependency تازه‌ای اضافه نشد. lockها و نسخه‌های ثبت‌شده در شواهد باید مبنای نصب تمیز آینده باشند.

نمونهٔ دارای کیفیت PASS این کمپین، گزارش ذخیره‌شدهٔ `live/C-L1/report.html` در پوشهٔ شواهد است. متن آن تازه با LLM تولید شده، اما اجرای عددی منبع تاریخی است و حل تازه‌ای انجام نشده است. L4 نمونهٔ مردود برای مشاهدهٔ ایراد است؛ C-E1-R اجرا نشده است. نمایش گزارش ذخیره‌شده برای استاد باید از اجرای تازه با مصرف API و ارزیابی عددی تفکیک شود.

پیش از شروع آماده‌سازی تحویل، کیفیت Q5/Q6 و پذیرش نهایی باید بسته شوند. سپس کارهای مرحلهٔ بعد شامل بستهٔ قابل انتقال، راهنمای نصب و استفاده، آزمون محیط تمیز و رایانهٔ مقصد، بررسی مسیرهای قابل نوشتن و پورت‌ها، راهنمای خطایابی و پاک‌سازی دادهٔ خصوصی از بستهٔ توزیع است. `packaging_validation` و `professor_machine_installation` همچنان **NOT_RUN** هستند.
