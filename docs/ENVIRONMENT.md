# محیط و تصمیم‌های اجرایی

پوشهٔ کار یک مخزن Git خالی روی `main` بود. در زمان بررسی commit، remote، فایل پروژه یا دستور محلی AGENTS.md یافت نشد. Python پیش‌فرض 3.14.8 بود. برای انطباق با قرارداد، Python 3.12.16 در فضای جدا نصب شد و virtualenv پروژه از همان مفسر ساخته شد. بستهٔ انتشار از مفسر سیستم کاربر که با ۳٫۱۲ سازگار است استفاده می‌کند.

محیط مشاهده‌شده macOS 27.0.1، build 26A434، arm64، مدل Mac17,16، ۱۵ پردازندهٔ منطقی و ۲۴ GiB حافظه است. نسخه‌های عمدهٔ محیط آزمون NumPy 1.26.0، MEALPY 3.0.3، FastAPI 0.162.2، LangGraph 1.2.20، Pydantic 2.14.3، Streamlit 1.67.0، keyring 25.7.0 ، PyArrow 23.0.1 و SQLite 3.53.1 بودند.

MEALPY 3.0.3 سقف NumPy 1.26.0 دارد. نصب اولیه با opfunu 1.0.4 در Python 3.12 رد شد. نسخهٔ 1.0.1 در lock ثبت شد و نصب مجدد با `pip check` گذشت. قیود پلتفرمی lock برای سه خانواده تولید شده‌اند. PyArrow 26.0.1 در نمایش جدول خطای سازگاری NumPy داد. PyArrow 23.0.1 در lock نهایی و آزمون مرورگر استفاده شد. اجرای واقعی فقط روی محیط‌های فهرست‌شده در گزارش آزمون تأیید شده است.

backend، worker و رابط هرکدام فرایند جدا دارند. حل عددی از spawn استفاده می‌کند. فقط کلید نشست یا مخزن امن سیستم‌عامل در backend برای اتصال مدل استفاده می‌شود. سیاست‌های بدون LLM از مسیر عددی مشترک استفاده می‌کنند. هزینهٔ پولی به دلیل نبود جدول قیمت معتبر نامشخص گزارش می‌شود.
